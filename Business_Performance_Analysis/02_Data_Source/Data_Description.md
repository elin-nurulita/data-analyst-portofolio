# Data Source & Description

## 1. Data Source Overview

This project uses four primary datasets initially provided in Microsoft Excel format. The files were converted into CSV format before being imported into Google BigQuery for further processing and analysis.

The datasets consist of:

1. Ads
2. Artikel
3. Chat
4. Pesanan

**BigQuery Environment:**
- Project ID: `portfolio-473815`
- Dataset: `motocycle`

The four datasets serve different analytical purposes and are integrated to evaluate advertising performance, organic content performance, customer engagement, and sales application outcomes.

---

# 2. Ads Dataset

## 2.1 Dataset Overview

The Ads dataset contains advertising performance data used to monitor and evaluate paid marketing activities.

It provides information about advertising campaigns, content characteristics, audience targeting, advertising expenditure, audience reach, impressions, link clicks, and generated results.

## 2.2 Data Attributes / Column Description

| Column Name | Description |
|---|---|
| THBL | Year and month when the advertising content was published. |
| TGL | Date when the advertising content was active. |
| nama konten | Name of the advertising content. |
| Area | Geographical area where the advertisement was displayed. |
| Day | Date associated with the advertising content placement. |
| Campaign name | Name of the advertising campaign. |
| Ad set name | Name of the advertising ad set. |
| Range | Target audience age range. |
| Objective | Advertising campaign objective. |
| Results type | Type of advertising result, such as messages. |
| Results | Number of results or incoming chats generated by the advertising content. |
| Reach | Number of unique accounts reached by the advertising content. |
| Impressions | Total number of times the advertising content was displayed. |
| Link clicks | Number of clicks generated by the advertising content. |
| Act cost | Actual advertising expenditure. |
| Cost per Result | Advertising cost incurred for each generated result or incoming chat. |

### Derived Field from Data Cleaning

| Column Name | Description |
|---|---|
| Cost per Result adj | Adjusted cost-per-result field created during data cleaning. When the original Cost per Result value is unavailable or invalid, the field uses Act cost as a fallback value. |

## 2.3 Business Purpose

The Ads dataset is used to evaluate the effectiveness and efficiency of paid advertising activities.

It helps monitor advertising expenditure, measure the number of incoming chats generated by advertisements, evaluate audience engagement, and identify advertising content that delivers better performance.

## 2.4 Data Usage in Analysis

The Ads dataset was utilized in Google BigQuery and Power BI for advertising performance analysis.

Key applications include:

- Aggregating advertising costs, results, reach, impressions, and link clicks by content.
- Calculating cost per result.
- Comparing advertising costs and generated results across different content.
- Combining advertising data with Chat records to analyze attributed applications.
- Developing advertising performance KPIs and visualizations.

**Power BI Implementation:**

The Ads dataset supports the following DAX measures:

- Total Costs
- Total Results
- Cost per Result (Message)

It is primarily used in the Ads Performance dashboard and also contributes to the overall Business Performance dashboard.

# 3. Artikel Dataset

## 3.1 Dataset Overview

The Artikel dataset contains SEO article performance data used to monitor and evaluate organic marketing activities.

It provides information about article identification, article titles, audience engagement, impressions, views, link clicks, and incoming chats generated by individual articles.

## 3.2 Data Attributes / Column Description

| Column Name | Description |
|---|---|
| Kode Artikel | Article code used to identify an article. |
| Article name | Name or title of the SEO article. |
| View | Total number of article views. |
| Like | Total number of likes received by the article. |
| Impression | Total number of times the article was displayed. |
| Link clicks | Number of clicks generated by the article. |
| chat masuk | Number of incoming chats generated by the article. |

### Derived Field from Data Cleaning

| Column Name | Description |
|---|---|
| Group Artikel | Article group extracted from the article name using SQL SPLIT and TRIM functions. |

## 3.3 Business Purpose

The Artikel dataset is used to evaluate the effectiveness and performance of organic marketing activities.

It helps monitor the performance of published articles, evaluate audience engagement, and identify which articles deliver better results in attracting audiences and generating incoming chats.

## 3.4 Data Usage in Analysis

The Artikel dataset was utilized in Google BigQuery and Power BI to evaluate SEO content performance.

Key applications include:

- Grouping articles based on article names.
- Comparing generated results across article groups.
- Evaluating article performance based on impressions, views, likes, and link clicks.
- Identifying top-performing articles across different engagement metrics.
- Supporting the analysis of organic content and generated incoming chats.

**Power BI Implementation:**

The Artikel dataset supports the SEO Performance section of the SEO & Sales Performance dashboard, including:

- Results by Article Group.
- Article Performance Table.
- Article impressions, views, likes, and clicks.
- Article group filtering.

# 4. Chat Dataset

## 4.1 Dataset Overview

The Chat dataset contains detailed records of incoming customer conversations, used to monitor and evaluate sales performance in handling customer inquiries and follow-up activities.

It provides information about customer discussions, conversation timestamps, assigned sales personnel, follow-up outcomes, chat sources, content attribution, and associated application numbers.

## 4.2 Data Attributes / Column Description

| Column Name | Description |
|---|---|
| Id | Unique identifier for each incoming chat record. |
| Discussion id | Unique identifier for each customer discussion, associated with a customer phone number. |
| Date | Date when the customer chat was recorded. |
| Created at | Timestamp when the conversation started. |
| Completed at | Timestamp when the conversation ended or was completed. |
| Pic | Name of the sales representative responsible for handling the conversation. |
| Pic employee id | Unique employee identifier of the assigned sales representative. |
| Fu category | Follow-up category indicating the outcome of the sales follow-up activity. |
| Source | Source or channel through which the customer conversation was received. |
| Content name | Name of the advertising or organic content associated with the incoming chat. |
| Phone number | Customer phone number. |
| Application number | Application/order reference associated with the customer conversation. |

## 4.3 Business Purpose

The Chat dataset is used to evaluate sales effectiveness in handling customer inquiries and follow-up activities.

It helps monitor customer engagement, evaluate sales workload, identify lead sources, and assess the effectiveness of customer interactions in generating applications.

## 4.4 Data Usage in Analysis

The Chat dataset was utilized in Google BigQuery and Power BI to analyze customer engagement and sales performance.

Key applications include:

- Counting incoming customer discussions.
- Identifying discussions that received responses.
- Monitoring chat handling performance by PIC.
- Evaluating chat-to-order conversion rates.
- Identifying applications generated from advertising and organic content.
- Combining chat records with Ads and Pesanan datasets for cross-dataset analysis.

**Power BI Implementation:**

The Chat dataset supports the following DAX measures:

- Chat Respon
- PESANAN
- Chat to Order Conversion

It is also used to develop the following dashboard visualizations:

- Incoming Chat vs Responded Chat by PIC.
- Chat Response-to-Order Conversion Rate by PIC.

# 5. Pesanan Dataset

## 5.1 Dataset Overview

The Pesanan dataset contains customer application records and business process information used to monitor application progress, survey outcomes, and order status.

It provides information about customer applications, customer details, sales assignments, application dates, survey results, SLIK classifications, and motorcycle product information.

## 5.2 Data Attributes / Column Description

### A. Application Information

| Column Name | Description |
|---|---|
| No pengajuan | Unique identifier for each application. |
| Tanggal Pengajuan | Date when the application was submitted. |
| Tanggal Survey | Date when the customer survey was conducted. |
| Status Survey | Survey outcome, categorized as ACC, TACC, or Belum Survey. |
| Status PK | Application or order processing status, ranging from INP1 to CLSD. |
| Hasil SLIK | Result of the customer's SLIK assessment. |
| Sumber Leads | Source of the customer lead, such as Ads or Organic. |
| Tanggal Konten Dipasang | Date when the associated content was published. |

### B. Customer Information

| Column Name | Description |
|---|---|
| No KTP | Customer identification number. |
| Nama konsumen | Customer name. |
| No Telp | Customer phone number. |
| Alamat konsumen | Customer residential address. |

### C. Sales & Survey Information

| Column Name | Description |
|---|---|
| Nama sales | Name of the sales representative handling the application. |
| NIP Sales | Unique employee identifier of the sales representative. |
| Nama SPV | Name of the sales supervisor. |
| NIP SPV | Unique employee identifier of the sales supervisor. |
| Nama Petugas Survey | Name of the survey officer assigned to the application. |
| NIP Petugas Survey | Unique employee identifier of the survey officer. |

### D. Motorcycle Information

| Column Name | Description |
|---|---|
| Harga Motor | Price of the selected motorcycle. |
| Series | Motorcycle series associated with the application. |
| Kode Motor | Motorcycle product code. |
| Warna Motor | Color of the selected motorcycle. |

### E. Marketing & Advertising Attribution

|---|---|
| Campaign name | Name of the associated advertising campaign. |
| Ad set name | Name of the advertising ad set. |
| Range | Target audience age range associated with the advertising activity. |
| Objective | Advertising campaign objective. |
| Results type | Type of advertising result. |
| Results | Number of results generated by the advertising activity. |
| Reach | Number of accounts reached by the advertising content. |
| Impression | Total number of advertising impressions. |
| Link clicks | Number of clicks generated by the advertising content. |
| Act cost | Actual advertising expenditure. |
| Cost per Result | Advertising cost per generated result. |

## 5.3 Business Purpose

The Pesanan dataset is used to monitor and evaluate the application processing workflow, from initial submission to survey outcomes and order completion.

It helps the business track application progress, evaluate survey results, monitor order statuses, identify lead sources, assess application quality based on SLIK classifications, and understand motorcycle product demand.

## 5.4 Data Usage in Analysis

The Pesanan dataset was utilized in Google BigQuery and Power BI to analyze application performance and business process outcomes.

Key applications include:

- Analyzing application distribution by submission date.
- Monitoring application distribution by order status.
- Evaluating survey outcomes based on ACC and TACC classifications.
- Analyzing application distribution by SLIK classification.
- Calculating delivered orders and indent applications.
- Evaluating approval and rejection rates based on SLIK classification.
- Integrating application records with Chat data through application numbers.
- Evaluating application distribution across motorcycle series.

**Power BI Implementation:**

The Pesanan dataset supports the following DAX measures:

- Delivered order
- Indent
- % ACC
- % TACC

It also contributes to the Business Performance dashboard and the application-related analysis across the integrated Power BI model.

# 6. Dataset Integration Summary

The four datasets provide complementary information for integrated business analysis.

| Dataset | Main Business Focus | Primary Analytical Role |
|---|---|---|
| Ads | Paid Advertising Performance | Evaluate advertising expenditure, reach, engagement, and generated results. |
| Artikel | Organic / SEO Performance | Evaluate article engagement and organic results. |
| Chat | Customer Engagement & Sales Follow-up | Analyze incoming discussions, responses, lead sources, and sales conversion. |
| Pesanan | Application & Order Processing | Analyze application outcomes, processing status, SLIK classification, and product demand. |

Together, these datasets support an integrated view of business performance across marketing, customer engagement, and sales operations.
